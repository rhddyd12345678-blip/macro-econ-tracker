# 수동 전망 입력 가이드

`data/forecasts_manual.csv`에 아래 출처들의 전망치를 사람이 직접 찾아 입력한다.
이 출처들은 저작권 있는 PDF·보도자료이거나(한국은행·일본은행·BMSI), 이번 조사에서
자동 접근이 막힌 곳이라(ECB SPF) 자동 수집 대상에서 뺐다(`시장전망_출처조사.md`
참고).

**원문의 문장·표를 그대로 옮기지 말 것.** 발표일·수치·출처 링크만 옮겨 적는다.

## CSV 열

| 열 | 필수 | 설명 |
|---|---|---|
| 발표일 | ✅ | 전망이 발표된 날짜 (YYYY-MM-DD) |
| 기관 | ✅ | 아래 "기관명" 표의 이름 그대로 |
| 국가 | ✅ | 한국 / 미국 / 일본 / 독일 / 프랑스 / 유로존 |
| 지표 | ✅ | 실질GDP성장률 / 소비자물가상승률 / 실업률 / 정책금리방향 등 |
| 대상기간 | ✅ | 연간이면 "2026", 분기면 "2026-Q3" |
| 전망치 | 설문형이 아니면 ✅ | 숫자만(%면 3.3처럼) |
| 응답비율_동결 / 응답비율_인상 / 응답비율_인하 | BMSI 등 설문형만 | %, 숫자만(예: 79) |
| 출처URL | ✅ | 원문 페이지 링크 |
| 비고 | 선택 | 특이사항 한 줄 |

전망치가 없는 행(설문 응답비율만 있는 행)은 `전망치` 칸을 비워둔다. 그 반대(응답비율이
없는 일반 전망치 행)는 응답비율 세 칸을 비워둔다.

## 기관명 (정확히 이 문자열로 입력)

| 기관명 | 대상 | 지표 |
|---|---|---|
| `한국은행` | 한국 | 실질GDP 성장률, CPI 헤드라인, CPI 근원 |
| `일본은행` | 일본 | 실질GDP 성장률, CPI 근원 (대상기간은 FY2026처럼 회계연도) |
| `금융투자협회 BMSI` | 한국 | 기준금리 방향 (응답비율_동결/인상/인하만 채움, 전망치는 비움. 대상기간에는 "2026-08-27 금통위"처럼 대상 금통위 날짜를 반드시 적는다 — 시장 전망 탭이 이 날짜로 지난 조사인지 판단한다) |
| `JCER ESP` | 일본 | 실질GDP 성장률(대상기간 FY형식), 정책금리 방향(응답비율만) |
| `ECB SPF` | 유로존 | 실질GDP 성장률, HICP 헤드라인, HICP 근원, 실업률 (자동 수집이 막혔을 때만 수동 입력) |

기관명·지표명은 위 표와 정확히 같은 문자열로 적어야 시장 전망 탭이 인식한다(예:
"금융투자협회"가 아니라 "금융투자협회 BMSI", "실질GDP성장률"이 아니라
"실질GDP 성장률" — 자동 수집 지표명과 띄어쓰기가 다르니 그대로 따라 쓸 것).

## 출처별로 숫자 찾는 곳

### 한국은행 경제전망보고서
- https://www.bok.or.kr/portal/bbs/P0002359/list.do?menuNo=200066
- 연 4회(2월·5월·8월·11월) 발표. 보고서 요약(본부장 기자간담회 자료 또는 본문 표)에서
  "실질GDP 성장률"과 "소비자물가" 올해·내년 전망치를 찾는다.
- 기준금리 자체의 숫자 전망은 발표하지 않으므로 입력하지 않는다.

### 일본은행 전망리포트 (Outlook Report)
- https://www.boj.or.jp/en/mopo/outlook/index.htm
- 연 4회(1월·4월·7월·10월) 발표, PDF만 제공. "The Bank's View" 요약에서
  실질GDP·CPI(정책위원 중앙값) 전망치를 찾는다.
- 저작권 안내가 불명확하므로(All Rights Reserved) 수치와 발표일만 옮기고,
  표·그래프를 캡처해서 올리지 않는다.

### 금융투자협회(KOFIA) 채권시장지표(BMSI) 기준금리 전망
- https://www.kofia.or.kr (채권시장지표 보도자료 검색) — 원문을 못 찾으면
  주요 경제지(연합뉴스, 이데일리, 뉴스핌 등)의 "채권시장지표" 관련 기사로 대체
  확인 가능(기사에 응답 비율이 그대로 인용됨).
- 매월 발표. "기준금리 동결/인상/인하 응답 비율"(%)을 응답비율_동결/인상/인하
  세 칸에 나눠 넣는다. 지표는 `정책금리방향`, 전망치 칸은 비운다.

### JCER ESP Forecast
- https://www.jcer.or.jp/english/esp-forecast
- 매월 발표(영문 요약 무료 공개). 일본 실질GDP 성장률 컨센서스(전문가 약
  37~40명 평균)를 찾는다. 상세 데이터는 회원 전용이라 공개 요약 수치만 쓴다.

### ECB Survey of Professional Forecasters (SPF) — 자동 수집 실패 시에만
- https://www.ecb.europa.eu/stats/ecb_surveys/survey_of_professional_forecasters/html/index.en.html
- `forecast_collect.py`가 매번 `data-api.ecb.europa.eu`로 자동 조회를
  시도하고, 이번 조사와 같은 이유로 계속 차단되면 이 페이지의 "Analyse the
  results" 도구에서 유로존 GDP·HICP·실업률 컨센서스를 직접 확인해 입력한다.
  자동 수집이 성공하면 이 항목은 입력할 필요가 없다(`forecast_collect.py`
  실행 로그에서 "ECB SPF" 상태를 확인).

## 확인

CSV를 저장한 뒤 `python3 forecast_collect.py`를 실행하면 이 파일을 읽어
`site/data/forecasts.json`에 자동으로 합쳐진다. 별도 처리는 필요 없다.
